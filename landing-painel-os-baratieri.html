Perguntas frequentes sobre o Painel OS Baratieri

O que é o Painel OS Baratieri?

É um software de gestão de ordens de serviço desenvolvido especialmente para luthiers. Permite controlar o fluxo de instrumentos em conserto em um quadro kanban, registrar orçamentos, fotos antes e depois, recebimentos e histórico completo de cada cliente.

Tem mensalidade?

Não. O Painel OS Baratieri é adquirido com pagamento único e licença vitalícia. Sem assinatura ou mensalidade de nenhum tipo.

Preciso ter comprado o Método Baratieri para usar o Painel OS?

Não necessariamente. O Painel OS Baratieri é um produto à parte. Quem já usa o Método tende a se adaptar mais rápido pela linguagem e rotina de oficina — mas qualquer luthier pode usar.

Os dados ficam na nuvem?

As OS ficam armazenadas localmente no seu navegador ou aparelho. Seus dados não passam por servidor externo. Por isso o backup em JSON é importante antes de trocar de celular ou limpar dados do site.

Funciona no celular?

Sim. O painel é responsivo e pode ser instalado como PWA na tela inicial — Android (Chrome) e iPhone (Safari). Funciona como um app nativo, sem precisar de loja de aplicativos.
